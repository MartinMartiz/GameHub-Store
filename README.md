## Descripción del Proyecto
GameHub Store es una plataforma e-commerce orientada al público gamer. En esta primera etapa (EP1) se implementa la capa de presentación navegable utilizando HTML5 semántico, CSS3 externo con variables y maquetación responsiva, y JavaScript para la dinamización del catálogo y validación de formularios.

## Estructura del Proyecto
* `/css/styles.css`: Hoja de estilos compartida.
* `/js/`: Scripts para simulación de datos, manipulación del DOM y validaciones.
* `/img/`: Recursos gráficos e imágenes del catálogo.
* Vistas principales: `index.html`, `catalogo.html`, `detalle.html`, `carrito.html`, `checkout.html`, `mis-ordenes.html`.

## Instrucciones de Ejecución
1. Clonar el repositorio: `git clone <URL_DEL_REPOSITO>`
2. Abrir la carpeta en Visual Studio Code.
3. Ejecutar el proyecto mediante una extensión de servidor local (ej. Live Server) o abriendo directamente `index.html` en el navegador.
